A GIS and Remote Sensing Based Vegetation Analysis

# Mapping Vegetation Patterns in Jim Corbett National Park Using NDVI

## Overview
This project explores vegetation patterns using Sentinel-2 imagery and NDVI generated in QGIS.

## Motivation
I built this project to learn remote sensing fundamentals and environmental GIS.

## Methods
- Sentinel-2 imagery
- Band extraction
- NDVI calculation
- Spatial interpretation

## Findings
- Vegetation distribution appeared patchy
- River-adjacent areas frequently showed higher NDVI
- Central areas were not uniformly vegetated

## Limitations
- Single-date analysis
- NDVI cannot determine ecological causes
- Canopy and mixed-pixel effects

## Tools
- QGIS
- Copernicus Browser
